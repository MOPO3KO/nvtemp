# nvtemp

Консольный монитор температур видеокарт NVIDIA в стиле `nvtop`. Показывает
температуру ядра и памяти каждой карты, рисует график изменения температуры во
времени символами псевдографики и выводит загрузку ядра и занятую видеопамять.

Программа написана на чистом Python и использует только стандартную библиотеку,
поэтому ничего устанавливать не нужно: достаточно драйвера NVIDIA и утилиты
`nvidia-smi`, которая ставится вместе с драйвером.

## Как запустить

```bash
python3 nvtemp.py
```

Полезные параметры запуска:

```bash
python3 nvtemp.py --interval 1       # как часто опрашивать карты, в секундах
python3 nvtemp.py --window 600       # сколько секунд истории показывать на графике
python3 nvtemp.py --slowdown 85      # порог температуры, по которому краснеют значения
```

Частота опроса по умолчанию — один раз в секунду, и во время работы она не
меняется. Длину видимого участка графика по умолчанию — 180 секунд — можно
менять клавишами (см. ниже).

## Клавиши

| Клавиша | Что делает |
|---------|------------|
| `q` | выход |
| `-` или `[` | уменьшить видимый участок графика на 10 секунд |
| `+` или `]` | увеличить видимый участок графика на 10 секунд |
| `s` | поднять порог температуры (по умолчанию 90 °C) на 5 градусов |
| `S` | опустить порог температуры на 5 градусов |
| `n` | переключить вид: все карты → карта 0 → карта 1 → … → снова все |

Длина видимого участка ограничена снизу 10 секундами, сверху — сутками.

## Что видно на экране

В обычном виде каждая карта занимает свой блок: название, две полосы заполнения
для температур ядра и памяти, затем график. В режиме одной карты сверху
появляется список всех карт, где у каждой в одних и тех же колонках показаны
температура ядра, температура памяти, загрузка ядра в процентах и занятая
видеопамять из общей:

```
>Device 0 [A100]                    TEMP  72°C  MEM  58°C  GPU  87%  VRAM 19.0G/24.0G
 Device 1 [Tesla V100-SXM2-32GB]    TEMP  72°C  MEM  58°C  GPU  87%  VRAM 19.0G/24.0G
 Device 2 [NVIDIA GeForce RTX 4090] TEMP  72°C  MEM  58°C  GPU  87%  VRAM 19.0G/24.0G
```

Колонки с числами начинаются сразу после самого длинного названия на экране,
поэтому у всех карт значения стоят на одном месте. На узком окне лишние колонки
справа убираются целиком, а не обрезаются посередине.

На графике две линии одного цвета для каждой карты: голубая — температура ядра,
зелёная — температура памяти. Правая граница графика всегда совпадает с последним
замером, поэтому линия постоянно касается правой рамки.

Если видеокарта или драйвер не отдают загрузку и объём памяти, в этих колонках
будет написано `N/A`, а остальное продолжит работать.

## Требования

- Linux или macOS с поддержкой `curses` (входит в стандартную библиотеку Python);
- Python 3.8 или новее;
- установленный драйвер NVIDIA с утилитой `nvidia-smi` в пути поиска программ.

## Тесты

Тесты не требуют видеокарты: вместо настоящего `nvidia-smi` подставляется
подставной скрипт из каталога `tests`. Запуск:

```bash
python3 -m unittest discover -s tests -p 'test_*.py' -v
```

Дополнительно есть проверки в настоящем терминале через `tmux`:

```bash
bash tests/sweep_quick.sh          # несколько размеров окна, быстро
bash tests/sweep_sizes.sh          # много размеров окна
bash tests/sweep_focus.sh          # то же плюс режим одной карты
```

`tests/repro_pty.py` запускает программу в псевдотерминале заданного размера,
например `python3 tests/repro_pty.py 10 46` — окно высотой 10 строк и шириной 46
колонок. Скрипт `tests/resize_pty.py` проверяет, что программа переживает
уменьшение окна во время работы.
